线代小帮手 —— 线性代数练习工具
线性代数课程数智实践大作业（选题 C3：实用数学小工具）。
功能（8 大模块）
行列式计算：输入 n×n 矩阵（n≤4，支持分数），给出按行展开的完整步骤与结果。
矩阵运算器：A±B、A×B、数乘、转置、逆矩阵（高斯—若尔当法）、秩（行最简形非零行数）、迹。
方程组求解：输入增广矩阵，自动做初等行变换化到行最简形，判定解的情况（唯一解 / 无解 / 无穷多解）并给出解。
特征值与特征向量（2×2）：特征多项式推导 → 判别式分析 → 特征值（精确根式 + 近似值）→ 特征向量；支持无实特征值情形。
行变换练习：自己逐步做初等行变换（交换两行 / 某行乘 k / 加 k 倍），工具逐步检查每一步是否合法、正确，并可一键查看标准做法。
找错挑战：自动生成一份含一处错误的解题过程，锻炼"看出错在哪一步"的能力。
随机刷题：行列式计算、方程组判定、矩阵的秩、矩阵乘法四类题型随机出题，即时反馈并附参考步骤；附累计做题数 / 答对数 / 正确率统计。
错题本：答错的题自动保存在浏览器本地（localStorage，离线可用，不上传数据）。
另有：深色模式（本地记忆）、首页功能导览、移动端自适应。
使用方式
无需安装任何东西，直接用浏览器打开 `index.html` 即可（可离线使用）。
技术说明
纯前端单页应用：原生 HTML / CSS / JavaScript，无第三方依赖。
所有有理数计算使用自定义分数类（Frac）进行精确运算，避免浮点误差；特征值模块在根式层面给出精确形式，向量部分给出近似值。
行列式：递归按第一行展开（Laplace 展开）。
方程组：高斯—若尔当消元法化行最简形，按秩与增广矩阵秩的关系判定解的情况。
逆矩阵：对 [A | I] 做同样的消元得到 [I | A⁻¹]，先以行列式是否为零判断可逆性。
特征值：λ² − tr(A)λ + det(A) = 0，按判别式分类讨论。
深色模式、学习统计、错题本均使用 localStorage 本地持久化。
